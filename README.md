# Netflix_Data_Analysis
Project Overview

This project analyzes Netflix dataset using Python to discover meaningful insights about movies and TV shows available on the platform.
The focus of this project is data cleaning, exploratory data analysis (EDA), and visualization.

Tools & Technologies

Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

Key Tasks Performed

Cleaned and preprocessed the dataset (handled missing values and removed duplicates)

Analyzed distribution of Movies vs TV Shows

Explored popular genres and content ratings

Studied year-wise growth of Netflix content

Created visualizations to identify trends and patterns

Key Insights

Significant growth in Netflix content after 2015

Movies dominate compared to TV Shows

Drama and Comedy are the most frequent genres

Conclusion

This project demonstrates my ability to clean raw data, perform exploratory data analysis, and extract insights using Python.
