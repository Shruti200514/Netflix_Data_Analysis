This project analyzes the Netflix dataset using Python to extract meaningful insights about movies and TV shows. It includes data cleaning, exploratory data analysis (EDA), and visualization to understand content distribution, genre popularity, ratings, and growth trends over the years. The analysis shows a major increase in content after 2015, with movies dominating the platform and Drama and Comedy being the most common genres.Drama and Comedy are the most frequent genres
